# 🎵 Fullstack Spotify Clone

A fullstack music streaming app inspired by Spotify, built with modern web technologies.

## 🚀 Tech Stack

- **Frontend:** React, Next.js 15, TypeScript, Tailwind CSS v4
- **Backend:** Supabase (Authentication, Database, Storage)
- **Other:** Server Components, API Routes, Responsive UI

## ✨ Features

- User authentication (Sign up, Sign in, Protected routes)
- Upload & manage songs with Supabase storage
- Play, pause, and skip tracks with an audio player
- Playlist management (create, update, delete)
- Fully responsive design with Tailwind CSS v4

## 📦 Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/alyadyh/spotify-clone.git
cd spotify-clone
npm install

```
